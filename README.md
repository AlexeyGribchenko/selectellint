# selectellint

**selectellint** — это статический анализатор (линтер) для Go, который проверяет логи. Он интегрируется с `golangci-lint` в качестве плагина.

**Что проверяет:**
*   **Регистр первой буквы:** сообщения должны начинаться со строчной буквы.
*   **Недопустимые символы:** обнаружение спецсимволов, эмодзи и символов других алфавитов (например, кириллицы).
*   **Чувствительные данные:** предупреждает о потенциально опасных словах в логах (`password`, `token`, `secret` и др.).

## Быстрый старт (Linux)

Эти инструкции помогут вам установить и запустить линтер на вашей локальной машине.

### Предварительные требования

Убедитесь, что в вашей системе установлены:
*   **Go** версии 1.24 или выше
*   **Git**
*   **GCC** (например, `build-essential` в Ubuntu/Debian или `gcc` в других дистрибутивах)
*   **golangci-lint** версии, совместимой с вашим проектом (рекомендуется последняя). [Инструкция по установке](https://golangci-lint.run/docs/)

### Установка плагина

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/AlexeyGribchenko/selectellint.git
    cd selectellint
    ```

2.  **Соберите и установите плагин с помощью Makefile:**
    ```bash
    # Проверит зависимости и соберет плагин (selectellint.so)
    make build

    # (Опционально) Установите плагин глобально (требует sudo)
    make install
    # Или установите локально в папку ./bin/ вашего проекта
    make install-local
    ```
    После выполнения команды `make install` плагин будет скопирован в `/usr/local/lib/selectellint.so`.

### Настройка проекта для использования линтера

1.  **Создайте или отредактируйте файл `.golangci.yml`** в корне вашего проекта, который вы хотите линтить.
2.  **Добавьте секцию для вашего плагина.** Скопируйте пример ниже и **обязательно измените поле `path`** на актуальный путь к файлу плагина.

    ```yaml
    # .golangci.yml
    version: "2"

    linters:
      settings:
        custom:
          selectellint:
            # ВАЖНО: Укажите правильный путь к файлу плагина!
            # Если вы использовали `make install`, путь будет таким:
            path: /usr/local/lib/selectellint.so
            # Если вы использовали `make install-local`, путь будет: ./bin/selectellint.so
            description: "Linter for logging messages"
            original-url: github.com/AlexeyGribchenko/selectellint
            # Настройки линтера (опционально)
            settings:
              check-capital: true      # Проверять первую букву
              check-invalid: true      # Проверять недопустимые символы
              check-sensitive: true    # Проверять чувствительные данные
              # Разрешенные символы (по умолчанию: A-Za-z0-9 и пробел)
              # allowed-symbols:
              # Символы, которые нужно заменять на пробел при авто-исправлении
              replace-with-space: "-_"
      enable:
        - selectellint
    ```

### Запуск

Теперь вы можете запустить `golangci-lint` как обычно в корне вашего проекта:
```bash
golangci-lint run
```
### Запуск в Docker

Так как разработка линтера велась на Windows, тестировать и собирать пришлось в Docker. В контейнер можно вмонтировать папку с проектом, который необходимо проверить линтером selectellint.
Сделать это можно при помощи команды
```bash
docker run -it --rm -v ${PWD}:/app selectellint-builder /bin/sh
```

Где вместо ${PWD} - абсолютный путь до папки с проектом.
